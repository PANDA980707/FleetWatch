# Ship Info: публикация

## Быстрый запуск на Render
1. Загрузите папку в репозиторий GitHub.
2. На render.com: New → Blueprint → выберите репозиторий (используется render.yaml).
3. Укажите AISSTREAM_API_KEY (ключ с aisstream.io) и ADMIN_EMAIL (ваш email: аккаунт с ним становится модератором). Деплой запустится сам.
4. Проверка: https://ВАШ-АДРЕС/health должен вернуть {"ok":true,...}. Подождите 1–2 минуты, пока накопятся суда.

Подойдёт любой хостинг с Docker или Node.js 18+ (Fly.io, Railway, VPS). Сервис должен работать постоянно, не «засыпать»: иначе данные пропадают и копятся заново. Бесплатные тарифы обычно засыпают.

## Переменные окружения
- AISSTREAM_API_KEY: обязательно
- BBOX: область подписки, например [[54,5],[62,25]]. По умолчанию весь мир (больше памяти и трафика)
- TILE_URL, TILE_ATTR: провайдер карты, например MapTiler или Stadia Maps (нужен их ключ в URL)
- ADMIN_EMAIL: email модератора. Зарегистрируйтесь с ним, и в разделе «Вакансии» появится модерация
- DB_PATH: путь к базе SQLite. Должен лежать на постоянном диске (в render.yaml это /data), иначе аккаунты и отзывы пропадут при перезапуске
- PORT: порт, по умолчанию 3000

## Перед публикацией
- Условия aisstream.io: сервис в бете, без гарантий доступности. Проверьте на сайте, разрешено ли коммерческое и публичное использование, и для серьёзного продукта рассмотрите платный источник AIS.
- Карта: публичные тайлы openstreetmap.org не рассчитаны на большую нагрузку. Для публики подключите коммерческий провайдер через TILE_URL.
- Отказ от ответственности: в карточке судна уже есть пометка, что данные не для навигации. Добавьте политику конфиденциальности (приложение ничего не собирает, но хостинг пишет IP в логи).
- Свой домен и HTTPS даёт хостинг. HTTPS нужен для установки приложения на телефон.

## Установка на телефон
Откройте сайт в Chrome (Android) или Safari (iPhone) → «Добавить на главный экран». Для Google Play упакуйте сайт через pwabuilder.com.

## Защита
Лимит 120 запросов в минуту с одного адреса, лимит 60 000 судов в памяти, суда без сигнала 30 минут удаляются.

## Аккаунты, отзывы, вакансии
- Регистрация по email и паролю, роли «моряк» и «крюинговое агентство». Пароли хранятся хешами (scrypt).
- Отзывы о судах: один отзыв от пользователя на судно, оценка 1–5. Три жалобы от разных пользователей скрывают отзыв автоматически, модератор может вернуть или скрыть его.
- Вакансии: публикуют только агентства, объявление сначала попадает на проверку модератору. Проверяйте агентства вручную и отклоняйте объявления, где просят деньги за найм.
- Резервные копии: копируйте файл базы (DB_PATH) регулярно.
- Не сделано: подтверждение email, восстановление пароля, редактирование и удаление своих объявлений, удаление аккаунта. Для первых двух нужен почтовый сервис (например Resend или Mailgun).
- Нужна политика конфиденциальности и условия использования: вы храните email, имена и тексты пользователей. Если среди пользователей люди из ЕС, подпадаете под GDPR.
